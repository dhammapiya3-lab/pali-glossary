# 빠알리 용어집 근거자료

빠알리 용어의 **개념정의**와 그 근거 자료(6차 결집본 빠알리 원문, 미얀마어 삼장사전, 닛사야)를 함께 찾아보는 검색 사이트의 원본 저장소입니다.

- 운영 중인 사이트(Claude 아티팩트): https://claude.ai/artifact/W2ahQ8R1NJsYRGYqPXU2UN
- 개념정의 표제어: 4,128어 (원본 4,215어, 2026-11-21 기준 — `data/build-info.json`)
- 출판사 번역어: 초기불전연구원 · 한국빠알리성전협회 · 불방일 · 고요한소리

- **[LICENSE.md](LICENSE.md)** — 라이선스 정리

## 바로 보기
- GitHub Pages를 켜면(Settings → Pages → main, /(root)) 이 저장소 그대로 사이트가 열립니다.
- 내 컴퓨터: 이 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000
- 「Claude에게 바로 묻기」·질문 기록(계정 저장)·자료 내려받기는 claude.ai 안에서만 동작합니다. 다른 곳에서는 다른 AI에 붙여 넣을 자료 복사 방식으로 바뀝니다.

## 업데이트
개념정의 원본(Google Drive)이 바뀌면 매일 새벽 자동으로 사이트와 이 저장소가 함께 갱신됩니다. 사이트 화면을 고칠 때도 이 저장소에 함께 올립니다.
